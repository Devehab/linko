# linko brand assets

A rounded square — your machine — linked to a ring — the public internet — with
a deliberate gap where the two meet: the tunnel. Every file here is generated
geometry: pure paths, no masks, no embedded fonts, no external references, so
each one renders identically in a browser, a README, a favicon and a print PDF.

| File | Use |
| --- | --- |
| `logo.svg` | The mark. Default choice. |
| `logo-mono.svg` | The mark in `currentColor` — inherits the surrounding text colour. |
| `logotype.svg` · `.png` | Mark + wordmark lockup. Use in headers and READMEs. |
| `wordmark.svg` | The wordmark alone. |
| `icon.svg` · `apple-touch-icon.png` | App icon, on the dark background. |
| `favicon.svg` | The mark with tighter margins, for 16–32 px. |
| `og.png` | Social preview card, 1200×630. |

## Colour

The gradient runs `#FFB457 → #F6821F → #DE4E08` on the 135° diagonal. `#F6821F`
alone is correct wherever a single flat colour is needed. On a dark surface use
`#0B0D12` behind it; the mark also holds up on white without modification.

## Clear space and minimum size

Leave clear space equal to the ring's radius on every side. The mark stays
legible down to 16 px; below that, use `favicon.svg`. Do not recolour the
gradient, rotate the mark, add effects, or separate the two shapes.
