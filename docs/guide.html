What linko isما هو linko

linko is a command-line tool that gives a locally running service a public HTTPS address on a domain you own. You type one command; anyone in the world can then open your work in a browser. ‏linko أداة سطر أوامر تمنح خدمة تعمل على جهازك عنوانًا عامًا بـ HTTPS على دومين تملكه أنت. تكتب أمرًا واحدًا، فيستطيع أي شخص في العالم فتح عملك في متصفحه. 

$ npm run dev          # your app is on :3000
$ linko 3000           # in another terminal

✓ Tunnel connected
  Public URL  https://x92ka.example.com

It does this by driving Cloudflare Tunnel for you. What you would otherwise do by hand — create a DNS record, configure a reverse proxy, obtain a certificate, open a port on your router — linko does through the Cloudflare API in about two seconds, and undoes just as cleanly. يفعل ذلك بقيادة Cloudflare Tunnel نيابةً عنك. ما كنت ستفعله يدويًا — إنشاء سجل DNS، وإعداد reverse proxy، والحصول على شهادة، وفتح منفذ في الراوتر — يقوم به linko عبر واجهة Cloudflare في ثانيتين تقريبًا، ويتراجع عنه بنفس النظافة.

What it is notما ليس هو

  • Not a hosting service — your code keeps running on your machine. ليس خدمة استضافة — كودك يبقى يعمل على جهازك.
  • Not a paid tunnel provider — it uses your Cloudflare account, on the free plan. ليس مزوّد أنفاق مدفوعًا — يستخدم حسابك أنت على Cloudflare، بالخطة المجانية.
  • Not a replacement for production deployment — it is built for development, demos, webhooks and sharing. ليس بديلًا عن النشر الإنتاجي — مصمّم للتطوير والعروض وwebhooks والمشاركة.

Moving DNS to Cloudflareنقل DNS إلى Cloudflare

You are not transferring ownership. The domain stays registered where you bought it, you keep paying the same registrar, and you can undo this at any time. Only the nameservers change. أنت لا تنقل ملكية الدومين. يبقى مسجّلًا حيث اشتريته، وتستمر بالدفع لنفس الجهة، ويمكنك التراجع في أي وقت. الذي يتغيّر هو nameservers فقط.

  1. Create a free accountأنشئ حسابًا مجانيًا dash.cloudflare.com/sign-up
  2. Add your domainأضف دومينك Add a site → type example.com → choose the Free plan. اضغط Add a site ← اكتب example.com ← اختر خطة Free.
  3. Let it scan your recordsدع Cloudflare تفحص سجلاتك Cloudflare copies your existing DNS automatically. Compare the list against your current provider — especially MX records if you use email on that domain, or your mail will stop. ستنسخ سجلاتك الحالية تلقائيًا. قارن القائمة بمزوّدك الحالي — خصوصًا سجلات MX إن كان لديك بريد على هذا الدومين، وإلا توقّف بريدك.
  4. Copy the two nameserversانسخ الـ nameservers 
    dana.ns.cloudflare.com
rick.ns.cloudflare.com
  5. Paste them at your registrarضعهما عند بائع الدومين Find Nameservers / DNS settings / Custom DNS, remove what is there, and put Cloudflare's two in. ابحث عن Nameservers أو DNS settings أو Custom DNS، واحذف الموجود وضع اللذين نسختهما.
    Namecheap · GoDaddy · Google / Squarespace · Hostinger

Installالتثبيت

macOS, Linux, and Windows via Git Bash ‏macOS ولينكس وويندوز عبر Git Bash

curl -fsSL https://raw.githubusercontent.com/Devehab/linko/main/install.sh | bash

The script detects your platform, downloads the matching binary, and places it in a directory that is already on your PATH. If it has to fall back to ~/.local/bin, it adds that line to your shell profile for you. يكتشف السكربت نظامك، وينزّل الملف المناسب، ويضعه في مجلد موجود في مسارك أصلًا. وإن اضطر لاستخدام ~/.local/bin فسيضيف السطر إلى ملف الشِل بنفسه. 

linko --version
Verified weekly on twelve clean systems مُتحقَّق منه أسبوعيًا على اثني عشر نظامًا نظيفًا ubuntu · macOS · Windows Git Bash · debian 11 and 12 · ubuntu 22.04 and 24.04 · alpine · fedora · rocky 9 · arch · openSUSE leap — each with nothing preinstalled. ‏ubuntu وmacOS وويندوز عبر Git Bash، وdebian 11 و12، وubuntu 22.04 و24.04، وalpine وfedora وrocky 9 وarch وopenSUSE leap — كلها بلا أي شيء مثبّت مسبقًا.

The Cloudflare API tokenتوكن Cloudflare

One token, both permissions.توكن واحد، صلاحيتان معًا. Not one token for DNS and another for the tunnel — a single token carrying both rows. And both must be Edit, not Read. ليس توكنًا للـ DNS وآخر للنفق — بل توكن واحد يحمل السطرين. وكلتاهما Edit لا Read.
  1. Open the tokens pageافتح صفحة الرموز dash.cloudflare.com/profile/api-tokens → Create Token → Create Custom Token
  2. Add both permission rowsأضف السطرين في Permissions Press + Add more for the second row. اضغط + Add more لإضافة السطر الثاني.
    #123
    1ZoneDNSEdit
    2AccountCloudflare TunnelEdit
  3. Scope the resourcesحدّد الموارد Account Resources → your account.
    Zone Resources → Include → Specific zone → your domain.     Account Resources ← اختر حسابك.
    Zone Resources ← Include → Specific zone → دومينك.
    Leaving Zone Resources empty produces a token that authenticates successfully but sees no domains at all — you will get no zone named …. This is the single most common setup mistake. ترك Zone Resources فارغًا ينتج توكنًا يتصل بنجاح لكنه لا يرى أي دومين — وستحصل على no zone named …. هذا أشيع خطأ في الإعداد كله.
  4. Copy the tokenانسخ الرمز It is shown exactly once.يُعرض مرة واحدة فقط.

Forgot the steps later? linko docs prints them in your terminal. نسيت الخطوات لاحقًا؟ اكتب linko docs فتظهر في طرفيتك.

linko uninstall

Remove linko from the machine, and its traces from Cloudflare, in order: يزيل linko من الجهاز، وآثاره من Cloudflare، بهذا الترتيب:

  1. stop tunnels running in the background يوقف الأنفاق العاملة بالخلفية
  2. remove the services that start them at login يزيل الخدمات التي تشغّلها عند تسجيل الدخول
  3. delete your published URLs and their DNS records يحذف روابطك المنشورة وسجلات DNS الخاصة بها
  4. delete the tunnel from your Cloudflare account يحذف النفق من حساب Cloudflare
  5. delete ~/.linko — config, logs, the cloudflared copy يحذف ~/.linko — الإعداد والسجلات ونسخة cloudflared
  6. delete the linko binary itself يحذف ملف linko التنفيذي نفسه
-y, --yes Do not ask for confirmationبلا سؤال تأكيد
--keep-cloud Leave the URLs, DNS records and tunnel on Cloudflare اترك الروابط وسجلات DNS والنفق على Cloudflare
--keep-binary Leave the binary in placeاترك الملف التنفيذي مكانه

Your Cloudflare account, your domain and your API token are never touched — revoke the token yourself at the tokens page if you no longer want it. حسابك في Cloudflare ودومينك وتوكنك لا يُمسّون — ألغِ التوكن بنفسك من صفحة التوكنات إن لم تعد تريده.

Background and bootالخلفية والإقلاع

Close the terminal and the tunnel keeps running: أغلق الطرفية ويبقى النفق شغالًا:

linko 3000 -d      # detach, return to the prompt
linko ps           # what is running
linko stop web     # stop one
linko stop --all   # stop everything

Logs land in ~/.linko/logs/<name>.log. To survive a reboot: السجلات في ~/.linko/logs/<name>.log. وللبقاء بعد إعادة التشغيل:

linko service install 3000 --name crm
linko service list
linko service uninstall crm

A launchd agent on macOS, a systemd user unit on Linux, both restarting automatically if the tunnel ever stops. وكيل launchd على macOS، ووحدة systemd --user على لينكس، وكلاهما يعيد التشغيل تلقائيًا إن توقف النفق.

The one-level ruleقاعدة المستوى الواحد

Cloudflare's free Universal SSL covers exactly two names: شهادة Cloudflare المجانية تغطي اسمين اثنين بالضبط:

example.com        ← the apex
*.example.com      ← one level

A wildcard in a certificate does not cross a dot: و* في الشهادات لا تعبر النقطة:

URLWorks?يعمل؟
demo.example.com✅ *.example.com
demo.app.example.com ❌ two levels — nothing covers it مستويان — لا شيء يغطيه
The hardest failure to diagnose in the whole system أصعب عطل في النظام كله DNS is correct, the tunnel is connected, and linko doctor is entirely green — yet the browser refuses with ERR_SSL_VERSION_OR_CIPHER_MISMATCH, because the rejection happens before any request reaches your tunnel. linko init warns you up front. الـ DNS صحيح، والنفق متصل، وlinko doctor أخضر بالكامل — ومع ذلك يرفض المتصفح بـ ERR_SSL_VERSION_OR_CIPHER_MISMATCH، لأن الرفض يحدث قبل وصول أي طلب إلى نفقك. لهذا يحذّرك linko init مسبقًا.
Simplest free answerأبسط حل مجاني Put the distinction in the name itself: myapp-dev.example.com rather than myapp.dev.example.com. Two levels require Cloudflare Advanced Certificate Manager ($10/month per zone) plus Total TLS. اجعل التمييز في الاسم نفسه: myapp-dev.example.com بدل myapp.dev.example.com. المستويان يحتاجان Advanced Certificate Manager (‏١٠ دولارات شهريًا للدومين) مع تفعيل Total TLS.

When things change behind your back حين يتغيّر شيء من خلفك

Tokens expire. People delete tunnels from the dashboard. DNS records get removed by hand. linko notices all three, says so in plain terms, and repairs them. التوكنات تنتهي صلاحيتها، والأنفاق تُحذف من اللوحة، وسجلات DNS تُمسح يدويًا. يكتشف linko الثلاثة، ويقول لك ما حدث بوضوح، ثم يصلحه.

The new token is verified against Cloudflare before it is saved, so a typo cannot lock you out of your own configuration. يتحقق من التوكن الجديد قبل حفظه، فلا يمكن لخطأ مطبعي أن يقفل عليك إعدادك.

The tunnel was deletedالنفق حُذف

linko recreates it — or adopts one of the same name — fetches a fresh tunnel token, re-points every DNS record at the new tunnel (a new tunnel is a new CNAME target), and restores every route. يعيد linko إنشاءه — أو يتبنّى واحدًا بنفس الاسم — ويجلب توكنًا جديدًا، ويعيد توجيه كل سجلات DNS إلى النفق الجديد (لأن النفق الجديد يعني هدف CNAME جديدًا)، ويستعيد كل المسارات.

Everything at onceكل شيء دفعة واحدة

Repairs a dead token, a deleted tunnel, missing DNS records and missing routes, then re-runs the full check. Add --yes to skip the confirmations. يصلح التوكن الميت والنفق المحذوف وسجلات DNS والمسارات الناقصة، ثم يعيد الفحص كاملًا. أضف --yes لتخطّي التأكيدات.

Troubleshootingحل المشاكل

Every message below is a real error this project hit, with its actual cause. كل رسالة أدناه خطأ حقيقي واجهه هذا المشروع، وهذا سببها الفعلي.

Error: no zone named "example.com" on this account
Cause: the token is missing the Zone permission, or its Zone Resources are empty.
Fix: add Zone → DNS → Edit and include your domain. linko lists the zones the token can see, so you know immediately. السبب: التوكن ينقصه صلاحية Zone، أو أن Zone Resources فارغة.
الحل: أضف Zone → DNS → Edit مع تضمين دومينك. يعرض linko النطاقات التي يراها التوكن فتعرف فورًا أين الخلل.
✗ Cloudflare refused to create the DNS record. Authentication error (code 10000)
Cause: the DNS permission is Read, not Edit. Finding the zone needs only read access, so setup passes completely and the first write fails.
Fix: switch that dropdown to Edit. السبب: صلاحية DNS على Read بدل Edit. العثور على الـ zone يحتاج قراءة فقط، لذلك يمر الإعداد كاملًا ثم يفشل عند أول كتابة.
الحل: غيّر القائمة المنسدلة إلى Edit.
✗ Could not create the tunnel Authentication error (code 10000)
Cause: the token covers DNS but not tunnels.
Fix: add Account → Cloudflare Tunnel → Edit to the same token. السبب: التوكن يغطي DNS ولا يغطي الأنفاق.
الحل: أضف Account → Cloudflare Tunnel → Edit على نفس التوكن.
This site can't provide a secure connection ERR_SSL_VERSION_OR_CIPHER_MISMATCH
Cause: the hostname is two levels deep.
Fix: linko init --force --base example.com, or buy ACM. السبب: الرابط بعمق مستويين.
الحل: linko init --force --base example.com أو اشترِ ACM.
HTTP 502 · Error 1033
Cause: the tunnel is up but nothing is listening on the port.
Fix: check curl http://localhost:3000. If your app binds the loopback only, use linko 127.0.0.1:3000. السبب: النفق يعمل لكن لا شيء يستمع على المنفذ.
الحل: تحقق بـ curl http://localhost:3000. وإن كان تطبيقك يستمع على الـ loopback فقط، استخدم linko 127.0.0.1:3000.
zsh: command not found: linko
Cause: the install directory is not on your PATH.
Fix: reopen the terminal, or run exec $SHELL. The installer adds the line for you. السبب: مجلد التثبيت ليس في مسارك.
الحل: أعد فتح الطرفية أو نفّذ exec $SHELL. المثبّت يضيف السطر تلقائيًا.

Securityالأمان

  • Published URLs are public. Anyone with the link reaches your local service. Do not expose anything sensitive; put Cloudflare Access in front of the hostname if you need authentication. الروابط المنشورة عامة. أي شخص يملك الرابط يصل إلى مشروعك. لا تنشر بيانات حساسة، وإن احتجت مصادقة فضع Cloudflare Access أمام الاسم.
  • The token lives in ~/.linko/config.json with mode 0600. Never commit it — use LINKO_API_TOKEN for teams and CI. التوكن في ~/.linko/config.json بصلاحيات 0600. لا ترفعه إلى Git — استخدم LINKO_API_TOKEN للفرق وCI.
  • Nothing leaks into ps. The tunnel token reaches cloudflared through the environment, never on the command line. لا شيء يظهر في ps. توكن النفق يصل إلى cloudflared عبر البيئة لا عبر سطر الأوامر.
  • Foreign DNS records are never touched. If a hostname points at your real site, linko refuses to overwrite or delete it. لا يمسّ سجلات غيره. إن كان الاسم يشير إلى موقعك الحقيقي فلن يستبدله أو يحذفه.
  • Your IP address is never exposed. The connection is outbound only, so visitors reach Cloudflare, never your network. عنوان IP الخاص بك لا يظهر أبدًا. الاتصال صادر فقط، فيصل الزوار إلى Cloudflare لا إلى شبكتك.
