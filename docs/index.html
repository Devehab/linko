linko

أمر واحد يحوّل مشروعك المحلي إلى رابط HTTPS عام على دومينك.

$ linko 3000

✓ DNS record created (x92ka.example.com)
✓ Route published (x92ka.example.com -> http://localhost:3000)
✓ Tunnel connected

  Public URL  https://x92ka.example.com
  Forwards    http://localhost:3000

  Press Ctrl+C to stop

بدون فتح بورت، بدون Port Forwarding، بدون شهادات SSL، بدون إنشاء سجلات DNS يدويًا.

ما تحتاجه

  • حساب Cloudflare مجاني
  • دومين موجّهة nameservers الخاصة به إلى Cloudflare

‏cloudflared يُنزَّل تلقائيًا عند أول استخدام — لا تثبّته بنفسك.

١ · التثبيت

macOS و Linux

curl -fsSL https://raw.githubusercontent.com/Devehab/linko/main/install.sh | bash

للتحقق:

linko --version
‏command not found بعد التثبيت؟ مجلد التثبيت ليس في مسارك. أضف هذا السطر إلى ~/.zshrc ثم أعد فتح الطرفية: export PATH="$HOME/.local/bin:$PATH"

طرق أخرى: عبر Go بـ go install github.com/Devehab/linko@latest، أو نزّل الملف الجاهز لنظامك من صفحة الإصدارات (ويندوز: ملف .zip).

٢ · توكن Cloudflare

هذه الخطوة هي التي تتعثّر فيها الأغلبية. القاعدة في سطر واحد:

توكن واحد، صلاحيتان معًا. ليس توكنًا للـ DNS وآخر للنفق — بل توكن واحد يحمل الاثنتين. وكلتاهما Edit لا Read.
  1. افتح صفحة الرموز dash.cloudflare.com/profile/api-tokens ← Create Token ← انزل إلى الأسفل واختر Create Custom Token.
  2. أضف السطرين في قسم Permissions اضغط + Add more لإضافة السطر الثاني.
    #الأولالثانيالثالث
    ١ZoneDNSEdit
    ٢AccountCloudflare TunnelEdit
  3. حدّد الموارد في Account Resources اختر حسابك. وفي Zone Resources اختر Include → Specific zone → دومينك.
    إن تركت Zone Resources فارغًا فسيتصل التوكن بنجاح لكنه لن يرى أي دومين، وستحصل على no zone named ….
  4. انسخ الرمز يُعرض مرة واحدة فقط.

٣ · الإعداد

linko init

يسألك ثلاثة أسئلة: الرمز، ثم الدومين، ثم اسم النفق. اضغط Enter لقبول الافتراضي.

Cloudflare credentials
Cloudflare API token: (مخفي أثناء الكتابة)
✓ Cloudflare connected

Domain
Domain: [example.com]
✓ DNS zone found (example.com)
Base subdomain: [example.com]
✓ URLs will look like https://abc12.example.com

Tunnel
Tunnel name: [example-linko-tunnel]
✓ Tunnel created
✓ Configuration saved to ~/.linko/config.json
✓ cloudflared installed

You're ready.

سؤال «Base subdomain» — انتبه هنا

اترك الإجابة على الدومين نفسه: example.com لا تكتب demo.example.com. السبب في القسم التالي.

٤ · قاعدة المستوى الواحد

شهادة Cloudflare المجانية تُصدَر لاسمين اثنين فقط:

example.com        ← الجذر
*.example.com      ← مستوى واحد

و* لا تعبر النقطة — تطابق تسمية واحدة فقط:

الرابطيعمل؟
demo.example.com✅ يطابق *.example.com
demo.app.example.com❌ مستويان — لا شهادة تغطيه
هذا العطل هو الأصعب في التشخيص كله. الـ DNS صحيح، والنفق متصل، وlinko doctor أخضر بالكامل — ومع ذلك يرفض المتصفح الاتصال بـ ERR_SSL_VERSION_OR_CIPHER_MISMATCH، لأن الرفض يحدث قبل وصول أي طلب إلى نفقك. لهذا يحذّرك linko init منه مسبقًا.

تريد مستويين مثل demo.app.example.com؟ يلزمك Advanced Certificate Manager من Cloudflare (‏١٠ دولارات شهريًا للدومين)، ثم فعّل Total TLS. البدائل المجانية (Subdomain setup، إعداد CNAME جزئي) محصورة بخطط Enterprise وBusiness.

الأبسط والمجاني: استخدم المستوى الأول واجعل التمييز في الاسم نفسه — myapp-dev.example.com بدلًا من myapp.dev.example.com.

٥ · الاستخدام

شغّل مشروعك أولًا (مثلًا على المنفذ 3000)، ثم:

linko 3000

تحصل على اسم عشوائي مثل x92ka. الرابط يعيش ما دامت الأداة تعمل، وعند Ctrl+C يُحذف الاسم وسجل الـ DNS تلقائيًا — لا تتراكم لديك سجلات.

رابط ثابت

linko 3000 --name crm

النتيجة https://crm.example.com، ويبقى محفوظًا بعد الإيقاف.

الأوامر كلها

الأمرالوظيفة
linko initالإعداد لمرة واحدة
linko 3000رابط عشوائي مؤقت
linko 3000 --name crmرابط باسم ثابت
linko 3000 --keepيبقي الاسم العشوائي بعد الإيقاف

# نافذة طرفية لكل مشروع
linko 3000 -n web
linko 8080 -n api

٦ · حل المشاكل

كل ما يلي أخطاء حقيقية ظهرت أثناء التطوير، وهذه أسبابها الفعلية.

Error: no zone named "example.com" on this account
السبب: التوكن ينقصه صلاحية Zone، أو أن Zone Resources فيه فارغة.
الحل: عدّل التوكن وأضف Zone → DNS → Edit مع Zone Resources → Include → Specific zone → دومينك.
‏linko يعرض لك النطاقات التي يراها التوكن فعلًا، فتعرف فورًا أين الخلل.
✗ Cloudflare refused to create the DNS record.
  Authentication error (code 10000)
السبب: صلاحية DNS مضبوطة على Read بدل Edit. العثور على الدومين يحتاج قراءة فقط، لذلك يمر الإعداد كاملًا ثم يفشل عند أول كتابة.
الحل: غيّر القائمة المنسدلة من Read إلى Edit.
✗ Could not create the tunnel
  Authentication error (code 10000)
السبب: التوكن يغطي DNS فقط ولا يملك صلاحية النفق.
الحل: أضف السطر الثاني Account → Cloudflare Tunnel → Edit على نفس التوكن.
This site can't provide a secure connection
ERR_SSL_VERSION_OR_CIPHER_MISMATCH
السبب: رابطك بعمق مستويين. لا شهادة مجانية تغطيه.
الحل: أعد الإعداد بـ linko init --base example.com ليصبح الرابط name.example.com. أو اشترِ Advanced Certificate Manager.
Error: no API token: pass --token or set LINKO_API_TOKEN
السبب: شغّلت linko init --yes بلا رمز.
الحل: إما export LINKO_API_TOKEN='...' قبل الأمر، أو مرّر --token '...'.
HTTP 502 · Error 1033
السبب: النفق يعمل لكن لا شيء يستمع على المنفذ.
الحل: تأكد بـ curl http://localhost:3000. وإن كان تطبيقك يستمع على 127.0.0.1 فقط، جرّب linko 127.0.0.1:3000.

عند الشك، ابدأ من هنا

linko doctor

يفحص ثمانية أشياء بالترتيب — من وجود cloudflared إلى الاتصالات الحيّة — ويقول لك أين توقّف بالضبط.

بداية نظيفة تمامًا

linko remove --all --yes
rm -rf ~/.linko
linko init

كيف يعمل

‏linko ينشئ نفقًا واحدًا في حسابك، وكل مشروع يصبح اسمًا داخله موجّهًا إلى منفذ مختلف.

  crm.example.com   ──┐
                      │                     ┌──▶ localhost:3000
  api.example.com   ──┼──▶ Cloudflare Edge ─┼──▶ localhost:8080
                      │      (نفق واحد)      │
  test.example.com  ──┘                     └──▶ localhost:5173
                                ▲
                                │  اتصال صادر فقط
                          cloudflared على جهازك

عند تشغيل linko 3000 تحدث ثلاثة أشياء: يُنشأ سجل CNAME يشير إلى نفقك، وتُضاف قاعدة توجيه تربط الاسم بـ localhost:3000، ثم يُشغَّل cloudflared فيفتح اتصالًا صادرًا نحو Cloudflare. لا شيء على جهازك ينتظر اتصالات واردة — لهذا لا تحتاج لمسّ الراوتر أو جدار الحماية.

أمان

  • الرابط عام. أي شخص يملكه يصل إلى مشروعك. لا تنشر بيانات حساسة. للحماية أضف Cloudflare Access من لوحة Zero Trust.
  • الرمز محفوظ في ~/.linko/config.json بصلاحيات 0600 — لا ترفعه إلى Git. للفرق وCI استخدم LINKO_API_TOKEN.
  • لا يحذف سجلًا ليس له. إن كان الاسم يشير إلى موقعك الحقيقي فلن يلمسه linko إطلاقًا.
