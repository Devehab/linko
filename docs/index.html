linko

A public HTTPS URL for any local port — on your own domain. رابط HTTPS عام لأي منفذ محلي — على دومينك أنت.

No port forwarding. No reverse proxy. No SSL certificates. No manual DNS records. بدون فتح بورت، بدون Port Forwarding، بدون شهادات SSL، بدون سجلات DNS يدوية.

✓ Route published (x92ka.example.com -> http://localhost:3000)
✓ Tunnel connected

  Forwards    http://localhost:3000
  Tunnel      example-linko-tunnel

  Press Ctrl+C to stop

Why linkoلماذا linko

ngrok is excellent until you want your own domain, no session limits and no interstitial warning page. linko gives you that on top of your own Cloudflare account. ‏ngrok ممتاز حتى تريد دومينك أنت، بلا حدود جلسات وبلا صفحة تحذير وسيطة. يعطيك linko ذلك فوق حسابك في Cloudflare.

Your domainدومينك أنت Every URL lives under a domain you control. كل رابط تحت دومين تملكه بالكامل.
Stable URLsروابط ثابتة A port keeps its URL. Restarting your app never changes the link you shared. المنفذ يحتفظ برابطه. إعادة التشغيل لا تغيّر الرابط الذي أرسلته.
Automatic HTTPSHTTPS تلقائي Cloudflare issues and renews the certificate for you. ‏Cloudflare تصدر الشهادة وتجدّدها نيابة عنك.
One binaryملف تنفيذي واحد Written in Go. No Node, no Python, no runtime to install. مكتوب بـ Go. لا Node ولا Python ولا أي بيئة تشغيل.
One tunnel, many projectsنفق واحد لكل مشاريعك Each project is a hostname routed to a different local port. كل مشروع اسم داخل النفق موجّه إلى منفذ مختلف.
Runs anywhereيعمل كما تشاء Foreground, background, or started automatically at every boot. في المقدمة، أو بالخلفية، أو يبدأ مع كل إقلاع.
What you needما تحتاجه A free Cloudflare account and a domain whose nameservers point at Cloudflare. cloudflared is downloaded automatically — you never install it, and you do not need Go. حساب Cloudflare مجاني، ودومين موجّهة nameservers الخاصة به إلى Cloudflare. وcloudflared يُنزَّل تلقائيًا — لا تثبّته بنفسك، ولا تحتاج Go.

02The Cloudflare tokenتوكن Cloudflare

This is the step almost everyone gets wrong. The rule, in one line: هذه الخطوة التي تتعثّر فيها الأغلبية. القاعدة في سطر واحد:

One token, both permissions.توكن واحد، صلاحيتان معًا. Not one token for DNS and another for the tunnel — a single token carrying both rows. And both must be Edit, not Read. ليس توكنًا للـ DNS وآخر للنفق — بل توكن واحد يحمل السطرين. وكلتاهما Edit لا Read.
  1. Open the tokens pageافتح صفحة الرموز dash.cloudflare.com/profile/api-tokens → Create Token → Create Custom Token
  2. Add both permission rowsأضف السطرين في Permissions Press + Add more for the second row. اضغط + Add more لإضافة السطر الثاني.
    #123
    1ZoneDNSEdit
    2AccountCloudflare TunnelEdit
  3. Scope the resourcesحدّد الموارد Account Resources → your account.
    Zone Resources → Include → Specific zone → your domain.     Account Resources ← اختر حسابك.
    Zone Resources ← Include → Specific zone → دومينك.
    Leaving Zone Resources empty produces a token that authenticates successfully but sees no domains at all — you will get no zone named …. ترك Zone Resources فارغًا ينتج توكنًا يتصل بنجاح لكنه لا يرى أي دومين — وستحصل على no zone named ….
  4. Copy the tokenانسخ الرمز It is shown exactly once. يُعرض مرة واحدة فقط.

Forgot the steps? linko docs prints them in your terminal. نسيت الخطوات؟ اكتب linko docs وستظهر في طرفيتك.

04A port keeps its URLالمنفذ يحتفظ برابطه

The behaviour that makes linko pleasant to live with. السلوك الذي يجعل استخدام linko مريحًا يومًا بعد يوم. 

linko 3000     # first run  → https://x92ka.example.com
# Ctrl+C
linko 3000     # next run   → https://x92ka.example.com  (the same one)

A link you already shared keeps working across restarts, and your DNS does not fill up with dead records. When you do want to change it: الرابط الذي أرسلته يبقى يعمل بعد كل إعادة تشغيل، ولا تتراكم سجلات DNS ميتة في حسابك. وحين تريد التغيير فعلًا:

linko 3000 --temp Throwaway: deleted the moment you quit رابط لمرة واحدة، يُحذف لحظة الإيقاف

07The one-level ruleقاعدة المستوى الواحد

Cloudflare's free certificate covers exactly two names. شهادة Cloudflare المجانية تغطي اسمين اثنين بالضبط. 

example.com        ← the apex
*.example.com      ← one level

A wildcard in a certificate does not cross a dot: و* في الشهادات لا تعبر النقطة:

URLWorks?يعمل؟
demo.example.com✅ *.example.com
demo.app.example.com ❌ two levels — nothing covers it مستويان — لا شيء يغطيه
The hardest failure to diagnose in the whole system أصعب عطل في النظام كله DNS is correct, the tunnel is connected, and linko doctor is entirely green — yet the browser refuses with ERR_SSL_VERSION_OR_CIPHER_MISMATCH, because the rejection happens before any request reaches your tunnel. linko init warns you up front. الـ DNS صحيح، والنفق متصل، وlinko doctor أخضر بالكامل — ومع ذلك يرفض المتصفح بـ ERR_SSL_VERSION_OR_CIPHER_MISMATCH، لأن الرفض يحدث قبل وصول أي طلب إلى نفقك. لهذا يحذّرك linko init مسبقًا.
Simplest free answerأبسط حل مجاني Put the distinction in the name itself: myapp-dev.example.com rather than myapp.dev.example.com. Two levels require Cloudflare Advanced Certificate Manager ($10/month per zone) plus Total TLS. اجعل التمييز في الاسم نفسه: myapp-dev.example.com بدل myapp.dev.example.com. المستويان يحتاجان Advanced Certificate Manager (‏١٠ دولارات شهريًا للدومين) مع تفعيل Total TLS.

08How it worksكيف يعمل

One tunnel in your account. Each project is a hostname inside it, routed to a different local port. نفق واحد في حسابك، وكل مشروع اسم داخله موجّه إلى منفذ مختلف. 

  crm.example.com   ──┐
                      │                     ┌──▶ localhost:3000
  api.example.com   ──┼──▶ Cloudflare Edge ─┼──▶ localhost:8080
                      │      (one tunnel)   │
  test.example.com  ──┘                     └──▶ localhost:5173
                                ▲
                                │  outbound connection only
                          cloudflared on your machine
  1. A proxied CNAME is created, pointing at <tunnel-id>.cfargotunnel.com يُنشأ سجل CNAME مُوكَّل يشير إلى <tunnel-id>.cfargotunnel.com
  2. An ingress rule maps the hostname to http://localhost:3000 تُضاف قاعدة توجيه تربط الاسم بـ http://localhost:3000
  3. cloudflared starts and opens an outbound connection يُشغَّل cloudflared فيفتح اتصالًا صادرًا

Nothing on your machine listens for inbound connections, which is why no firewall or router change is ever needed. لا شيء على جهازك ينتظر اتصالات واردة — لهذا لا تحتاج لمسّ الراوتر أو جدار الحماية إطلاقًا.

09Troubleshootingحل المشاكل

Every message below is a real error this project hit, with its actual cause. كل رسالة أدناه خطأ حقيقي واجهه هذا المشروع، وهذا سببها الفعلي.

Error: no zone named "example.com" on this account
Cause: the token is missing the Zone permission, or its Zone Resources are empty.
Fix: add Zone → DNS → Edit and include your domain. linko lists the zones the token can see, so you know immediately. السبب: التوكن ينقصه صلاحية Zone، أو أن Zone Resources فارغة.
الحل: أضف Zone → DNS → Edit مع تضمين دومينك. يعرض linko النطاقات التي يراها التوكن فتعرف فورًا أين الخلل.
✗ Cloudflare refused to create the DNS record. Authentication error (code 10000)
Cause: the DNS permission is Read, not Edit. Finding the zone only needs read access, so setup passes completely and the first write fails.
Fix: switch that dropdown to Edit. السبب: صلاحية DNS على Read بدل Edit. العثور على الـ zone يحتاج قراءة فقط، لذلك يمر الإعداد كاملًا ثم يفشل عند أول كتابة.
الحل: غيّر القائمة المنسدلة إلى Edit.
✗ Could not create the tunnel Authentication error (code 10000)
Cause: the token covers DNS but not tunnels.
Fix: add Account → Cloudflare Tunnel → Edit to the same token. السبب: التوكن يغطي DNS ولا يغطي الأنفاق.
الحل: أضف Account → Cloudflare Tunnel → Edit على نفس التوكن.
This site can't provide a secure connection ERR_SSL_VERSION_OR_CIPHER_MISMATCH
Cause: the hostname is two levels deep.
Fix: linko init --force --base example.com, or buy ACM. السبب: الرابط بعمق مستويين.
الحل: linko init --force --base example.com أو اشترِ ACM.
HTTP 502 · Error 1033
Cause: the tunnel is up but nothing is listening on the port.
Fix: check curl http://localhost:3000. If your app binds the loopback only, use linko 127.0.0.1:3000. السبب: النفق يعمل لكن لا شيء يستمع على المنفذ.
الحل: تحقق بـ curl http://localhost:3000. وإن كان تطبيقك يستمع على الـ loopback فقط، استخدم linko 127.0.0.1:3000.
zsh: command not found: linko
Cause: the install directory is not on your PATH.
Fix: reopen the terminal, or run exec $SHELL. The installer adds the line for you. السبب: مجلد التثبيت ليس في مسارك.
الحل: أعد فتح الطرفية أو نفّذ exec $SHELL. المثبّت يضيف السطر تلقائيًا.

10Securityالأمان

URLs are publicالروابط عامة Anyone with the link reaches your local service. Put Cloudflare Access in front of the hostname if you need authentication. أي شخص يملك الرابط يصل إلى مشروعك. ضع Cloudflare Access أمام الاسم إن احتجت مصادقة.
The token is chmod 0600التوكن بصلاحيات 0600 Stored in ~/.linko/config.json. Never commit it — use LINKO_API_TOKEN for teams and CI. محفوظ في ~/.linko/config.json. لا ترفعه إلى Git — استخدم LINKO_API_TOKEN للفرق وCI.
Nothing leaks into psلا شيء يظهر في ps The tunnel token reaches cloudflared through the environment, never on the command line. توكن النفق يصل إلى cloudflared عبر البيئة، لا عبر سطر الأوامر.
Foreign records are safeسجلاتك الأخرى بأمان linko refuses to overwrite or delete any DNS record that does not point at a Cloudflare tunnel. يرفض linko استبدال أو حذف أي سجل DNS لا يشير إلى نفق Cloudflare.
