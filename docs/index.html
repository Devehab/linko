Sharing localhost should not be this hard مشاركة مشروعك المحلي لا يجب أن تكون بهذه الصعوبة

Every tunnel tool solves the first ten minutes and then gets in your way: random URLs that change on every restart, session limits, an interstitial warning page between your client and your work, and a domain that is never yours. كل أدوات الأنفاق تحلّ أول عشر دقائق ثم تقف في طريقك: روابط عشوائية تتغيّر مع كل إعادة تشغيل، وحدود جلسات، وصفحة تحذير وسيطة بين عميلك وعملك، ودومين ليس لك أبدًا.

A port keeps its URLالمنفذ يحتفظ برابطه

Run linko 3000 again tomorrow and you get the same address back. The link you shared keeps working; your DNS never fills with dead records. شغّل linko 3000 غدًا فيعيد لك العنوان نفسه. الرابط الذي أرسلته يبقى يعمل، ولا تتراكم سجلات ميتة في حسابك.

HTTPS, handledHTTPS جاهز

Cloudflare issues and renews the certificate. You never see a certbot command or a renewal cron job. ‏Cloudflare تصدر الشهادة وتجدّدها. لن ترى أمر certbot ولا مهمة تجديد مجدولة.

Nothing to installلا شيء تثبّته

One static binary. No Node, no Python, no Docker, no Go. cloudflared downloads itself on first use. ملف تنفيذي واحد ثابت الربط. لا Node ولا Python ولا Docker ولا Go. وcloudflared ينزّل نفسه عند أول استخدام.

One tunnel, many projectsنفق واحد لكل مشاريعك

web on 3000, api on 8080, docs on 5173 — each a hostname inside the same tunnel. ‏web على 3000 وapi على 8080 وdocs على 5173 — كل واحد اسم داخل النفق نفسه.

Background and bootالخلفية والإقلاع

-d detaches and returns your prompt. linko service install brings it back after a reboot. ‏-d يفصله ويعيد لك السطر، وlinko service install يعيده بعد كل إقلاع.

Repairs itselfيصلح نفسه

Token expired? Tunnel deleted from the dashboard? linko says so in plain words and fixes it — linko doctor --fix. انتهت صلاحية التوكن؟ حُذف النفق من اللوحة؟ يقول لك ما حدث بوضوح ويصلحه — linko doctor --fix.

Under the hoodتحت الغطاء

How it actually worksكيف يعمل فعلًا

linko creates one Cloudflare Zero Trust tunnel in your account. Each project becomes a hostname inside it, routed to a different local port. ينشئ linko نفقًا واحدًا في حسابك على Cloudflare، وكل مشروع يصبح اسمًا داخله موجّهًا إلى منفذ محلي مختلف. 

  crm.example.com   ──┐
                      │                      ┌──▶ localhost:3000
  api.example.com   ──┼──▶  Cloudflare Edge ─┼──▶ localhost:8080
                      │       (one tunnel)   │
  test.example.com  ──┘                      └──▶ localhost:5173
                                 ▲
                                 │  outbound connection only
                           cloudflared on your machine
1

A DNS recordسجل DNS

A proxied CNAME is created, pointing at <tunnel-id>.cfargotunnel.com. يُنشأ سجل CNAME مُوكَّل يشير إلى <tunnel-id>.cfargotunnel.com.

2

A routeقاعدة توجيه

An ingress rule maps that hostname to http://localhost:3000, stored on Cloudflare, not on disk. تُضاف قاعدة تربط الاسم بـ http://localhost:3000، محفوظة عند Cloudflare لا على قرصك.

3

An outbound connectionاتصال صادر

cloudflared dials out to Cloudflare. Nothing on your machine ever listens for inbound traffic. يتصل cloudflared بـ Cloudflare من الداخل للخارج. لا شيء على جهازك ينتظر اتصالات واردة.

Why that mattersلماذا هذا مهم

Because the connection is outbound, no firewall rule, router change or open port is ever needed — and your home IP address is never exposed. لأن الاتصال صادر، لا تحتاج أي قاعدة جدار حماية ولا تعديل راوتر ولا فتح منفذ — ولا يظهر عنوان IP الخاص بك للزوار إطلاقًا.
