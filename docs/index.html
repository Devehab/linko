linko

أداة سطر أوامر تحوّل أي مشروع يعمل على جهازك إلى رابط HTTPS عام، باستخدام حسابك ودومينك على Cloudflare. بدون فتح بورت، بدون Port Forwarding، بدون شهادات SSL. 

$ linko 3000

✓ DNS record created (x92ka.demo.example.com)
✓ Route published (x92ka.demo.example.com -> http://localhost:3000)
✓ Tunnel connected

  Public URL  https://x92ka.demo.example.com
  Forwards    http://localhost:3000
  Tunnel      example-linko-tunnel
  Lifetime    removed when you quit (use --keep to persist)

  Press Ctrl+C to stop

ما هو linko؟

تجربة شبيهة بـ ngrok، لكن فوق بنية Cloudflare التحتية وعلى دومينك أنت. تكتب أمرًا واحدًا فتحصل على رابط عام جاهز يمكنك إرساله لأي شخص.

روابطك على دومينكلا subdomains عشوائية من طرف ثالث — كل شيء تحت demo.example.com.
HTTPS تلقائيCloudflare تدير الشهادات نيابة عنك.
ملف تنفيذي واحدمكتوب بـ Go. بدون Node أو Python أو أي تبعيات.
تونل واحد لكل شيءمشاريع متعددة على منافذ مختلفة داخل نفس التونل.
روابط مؤقتة تُنظَّفالاسم العشوائي يُحذف تلقائيًا عند الإيقاف.
أسماء ثابتة--name crm يعطيك رابطًا يبقى كما هو دائمًا.
ما الذي تحتاجه قبل البدء؟ حساب Cloudflare مجاني، ودومين مُضاف إليه (nameservers موجّهة إلى Cloudflare). لا يعمل linko بدون دومين تملكه.

كيف يعمل

ينشئ linko تونل واحدًا في حسابك (Cloudflare Zero Trust Tunnel). كل مشروع يصبح hostname داخل هذا التونل، موجّهًا إلى منفذ محلي مختلف. 

  crm.demo.example.com  ──┐
                          │                     ┌──▶ localhost:3000
  api.demo.example.com  ──┼──▶ Cloudflare Edge ──┼──▶ localhost:8080
                          │     (one tunnel)     │
  test.demo.example.com ──┘                     └──▶ localhost:5173
                                    ▲
                                    │  outbound connection only
                                    │  (no inbound ports opened)
                              cloudflared on your machine

عندما تشغّل linko 3000 تحدث أربعة أشياء:

  1. يُنشأ سجل CNAME يشير إلى <tunnel-id>.cfargotunnel.com.
  2. تُضاف قاعدة ingress إلى إعدادات التونل تربط الـ hostname بـ http://localhost:3000.
  3. يُشغَّل cloudflared كعملية فرعية، ويفتح اتصالًا صادرًا نحو شبكة Cloudflare.
  4. تصل طلبات الزوار إلى Cloudflare ثم تُمرَّر عبر التونل إلى جهازك.
لماذا لا تحتاج فتح بورت؟ لأن الاتصال يبدأ من جهازك نحو Cloudflare وليس العكس. جدار الحماية والراوتر لا يحتاجان أي تعديل.

التثبيت

macOS و Linux — سكربت التثبيت

curl -fsSL https://raw.githubusercontent.com/ibtkrgo/linko/main/install.sh | bash

يكتشف السكربت نظامك ومعماريتك، وينزّل النسخة المناسبة إلى /usr/local/bin (أو ~/.local/bin إن لم تكن لديك صلاحيات).

تحديد مجلد أو إصدار معيّن

LINKO_INSTALL=$HOME/bin LINKO_VERSION=v0.1.0 \
  bash -c "$(curl -fsSL https://raw.githubusercontent.com/ibtkrgo/linko/main/install.sh)"

عبر Go

go install github.com/ibtkrgo/linko@latest

البناء من المصدر

git clone https://github.com/ibtkrgo/linko.git
cd linko
make deps     # تنزيل الاعتماديات وإنشاء go.sum
make verify   # gofmt + go vet + الاختبارات
make build    # ينتج ./linko

Windows

نزّل ملف .zip من صفحة الإصدارات، فك الضغط، وضع linko.exe في مجلد ضمن PATH.

التحقق من التثبيت

linko --version
linko --help
cloudflared؟ لست بحاجة لتثبيته يدويًا. ينزّله linko تلقائيًا إلى ~/.linko/bin/ عند أول استخدام، وإذا كان مثبتًا لديك مسبقًا فسيستخدم نسختك.

إنشاء API Token

يحتاج linko رمزًا (Token) لإدارة الـ DNS والتونل نيابة عنك.

  1. افتح صفحة الرموز اذهب إلى dash.cloudflare.com/profile/api-tokens ثم Create Token ← Create Custom Token.
  2. أضف الصلاحيتين المطلوبتين
    النوعالموردالصلاحيةلماذا
    ZoneDNSEditإنشاء وحذف سجلات CNAME
    AccountCloudflare TunnelEditإنشاء التونل وإدارة الـ routes
  3. حدّد النطاق في Zone Resources اختر Include → Specific zone → دومينك، وفي Account Resources اختر حسابك.
  4. انسخ الرمز يُعرض مرة واحدة فقط. احفظه في مكان آمن — ستلصقه في الخطوة التالية.
لماذا API Token وليس Global API Key؟ الـ Token محدود الصلاحيات وقابل للإبطال بشكل مستقل. أما الـ Global Key فيمنح صلاحية كاملة على كل شيء في حسابك — لا تستخدمه هنا.

ما معنى «Base subdomain»؟

هو الجزء الثابت من كل روابطك. إن اخترت demo.example.com فستكون روابطك crm.demo.example.com وapi.demo.example.com وهكذا. يمكنك كتابة demo فقط وسيكملها linko تلقائيًا.

إعداد غير تفاعلي (للـ CI أو السكربتات)

linko init --yes \
  --token $CF_API_TOKEN \
  --domain example.com \
  --base demo.example.com \
  --tunnel my-dev-tunnel
الخيارالوصف
--tokenرمز Cloudflare (أو استخدم متغير البيئة LINKO_API_TOKEN)
--domainالدومين المُدار في Cloudflare
--baseالـ subdomain الأساس للروابط
--tunnelاسم التونل (الافتراضي: <domain>-linko-tunnel)
--forceإعادة الإعداد فوق إعداد موجود
--yes, -yعدم طرح أي أسئلة (يفشل بدل أن يسأل)
--skip-downloadعدم تنزيل cloudflared الآن

الاستخدام اليومي

رابط عشوائي مؤقت

شغّل مشروعك أولًا (مثلًا npm run dev على المنفذ 3000)، ثم:

linko 3000

تحصل على اسم عشوائي مثل x92ka. الرابط يعيش ما دامت الأداة تعمل، وعند الضغط على Ctrl+C يُحذف الـ hostname وسجل الـ DNS تلقائيًا.

رابط باسم ثابت

linko 3000 --name crm
# أو الاختصار
linko 3000 -n crm

النتيجة: https://crm.demo.example.com — يبقى محفوظًا بعد الإيقاف ويعمل في كل مرة تشغّله.

الاحتفاظ باسم عشوائي

linko 3000 --keep

تعارض الأسماء

إذا كان الاسم مستخدَمًا لمنفذ مختلف، يسألك linko:

$ linko 5000 --name crm

! Hostname already in use: crm.demo.example.com
  currently -> http://localhost:3000
        new -> http://localhost:5000

What would you like to do?
  1. Replace the existing route
  2. Create another hostname
  3. Cancel
Choose: _
  • Replace — يوجّه الاسم نفسه إلى المنفذ الجديد.
  • Create another hostname — ينشئ اسمًا مشتقًا مثل crm-k3f9.
  • Cancel — لا يغيّر شيئًا.

لتخطي السؤال: --replace أو --yes.

حل المشاكل

«linko is not set up yet»

لم يُنشأ ملف الإعدادات بعد. شغّل linko init.

«cloudflare: Unauthorized to access requested resource»

الرمز ينقصه صلاحية. تأكد من وجود Zone → DNS → Edit وAccount → Cloudflare Tunnel → Edit معًا، وأن الـ Zone Resources تشمل دومينك.

«no zone named example.com on this account»

الدومين غير مضاف إلى Cloudflare، أو الـ nameservers لم تُوجَّه بعد، أو الرمز لا يرى هذه الـ zone.

الرابط يعطي خطأ 502 أو 1033

  • تأكد أن مشروعك يعمل فعلًا على المنفذ المذكور: curl http://localhost:3000.
  • بعض الأطر تستمع على 127.0.0.1 فقط — جرّب linko 127.0.0.1:3000.
  • شغّل linko status للتأكد من أن التونل متصل.

الرابط لا يُحل (DNS)

انتظر دقيقة — الانتشار سريع عادةً لكنه ليس فوريًا. ثم تحقق:

dig +short crm.demo.example.com
linko doctor

عرض السجلات الكاملة

linko 3000 --verbose --loglevel debug

بداية نظيفة تمامًا

linko remove --all --yes
rm -rf ~/.linko
linko init

أسئلة شائعة

هل الرابط عام للجميع؟

نعم. أي شخص لديه الرابط يستطيع الوصول لخدمتك المحلية. لا تنشره إن كانت الخدمة تحتوي بيانات حساسة. للحماية أضف طبقة Cloudflare Access من لوحة تحكم Zero Trust.

هل يظل الرابط يعمل بعد إغلاق الطرفية؟

لا. عند إيقاف linko يتوقف cloudflared ويصبح الرابط غير متاح. إن استخدمت --name فالإعداد يبقى محفوظًا، ويكفي تشغيل الأمر ثانيةً لإعادة تفعيله.

كم رابطًا أستطيع إنشاءه؟

لا حد عملي من جهة linko. الحدود هي حدود حسابك في Cloudflare.

هل يعمل مع WebSockets؟

نعم، Cloudflare Tunnel يدعمها بشكل كامل.

هل هذا مجاني؟

خطة Cloudflare المجانية تكفي تمامًا لهذا الاستخدام. التكلفة الوحيدة هي تسجيل الدومين.

ما الفرق بينه وبين ngrok؟

الروابط على دومينك أنت وتحت سيطرتك، بلا حدود جلسات أو صفحات تحذير وسيطة، وباستخدام حسابك في Cloudflare. بالمقابل يتطلب linko دومينًا وإعدادًا أوليًا لمرة واحدة.

هل يمكن استخدامه في الإنتاج؟

التونل نفسه تقنية إنتاجية من Cloudflare، لكن linko مصمم لسير عمل التطوير والعروض التوضيحية. للإنتاج استخدم cloudflared كخدمة نظام (systemd / launchd).

ملاحظات تصميمية

  • التونل مُدار عن بُعد (config_src: cloudflare) — لا ملفات YAML محلية، والإعدادات مصدرها Cloudflare.
  • رمز التونل يُمرَّر عبر البيئة (TUNNEL_TOKEN) وليس عبر سطر الأوامر، حتى لا يظهر في ps.
  • قاعدة catch-all دائمًا في النهاية — تُطبَّع قائمة الـ ingress قبل كل عملية حفظ.
  • الكتابة ذرّية — يُكتب ملف الإعدادات في ملف مؤقت ثم يُعاد تسميته.
  • تبعية واحدة — Cobra فقط؛ باقي الكود يعتمد على المكتبة القياسية.

linko — واجهة مطوّر ذكية فوق Cloudflare Tunnel.

القيمة ليست في التونل نفسه، بل في أن تكتب أمرًا واحدًا وتحصل على رابط عام جاهز.
