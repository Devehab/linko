# التنفيذ العملي — نظام ترجمة لغة الإشارة

نظام **يعمل فعليًا** من الصفر: أفاتار مُهيكل أصلي، أبجدية ASL مشتقة من وصف أشكال اليد، محرّك ترجمة قائم على قواعد، وصيغة ضغط حركة مطابقة في بنيتها لما يستخدمه Hand Talk.

**لا يستخدم أي موديل أو بيانات حركة من طرف ثالث.** كل شيء مُولَّد بالأدوات الموجودة في `tools/`.

---

## التشغيل في 30 ثانية

```bash
cd impl
npm install            # esbuild + three + gltf-validator (تطوير فقط — الخادم بلا تبعيات)
npm run build          # يولّد الأفاتار + الإشارات + يحزم محرك 3D
npm run dev            # http://localhost:8787
```

افتح `http://localhost:8787` ثم اضغط الزر الأزرق أسفل يمين الصفحة، وبعدها انقر على أي نص.

```bash
npm test               # 35 اختبارًا: تكافؤ المُفكِّك + عقد الـ API + الأصول
```

## المفاهيم المُطبَّقة بالكامل

### 1. التحميل الكسول ذو المرحلتين
`sla-plugin.js` وحده يُحمَّل مع الصفحة. `three.js` والأفاتار لا يُلمسان حتى يضغط المستخدم الزر. زائر لا يستخدم الميزة لا يدفع ثمنها.

### 2. صيغة HTA
```
BH*0#5#11#16*-7#-7#-7#-7*-16#-16#-16#-16*-17#-17#-17#-17
│  │          │            │              └ الدوران حول Z
│  │          │            └────────────── الدوران حول Y
│  │          └─────────────────────────── الدوران حول X (درجات ÷ 2.7)
│  └────────────────────────────────────── الإطارات عند 24 fps
└───────────────────────────────────────── كود العظمة (BH = hips)
```
- `?` يفصل المسارات · `*` يفصل الحقول · `#` يفصل القيم · الفراغ = صفر
- العظام الساكنة **لا تُرسل** — المُفكِّك يعيدها لوضع الراحة
- أول حرف في `UVWXYZ` ⇒ morph target بدل عظمة

### 3. الأبجدية مشتقة لا مؤلَّفة
كل حرف موصوف مرة واحدة كـ **شكل يد**: قيمة انثناء لكل إصبع + تباعد + وضع الإبهام. المُصرِّف يحوّلها إلى زوايا مفاصل. هذا ما يجعل بناء قاموس التهجئة عمليًا.

```python
'V': H(0.85, 0.00, 0.00, 1.00, 1.00, spread=1.00),
#     إبهام سبابة وسطى بنصر خنصر
```

### 4. الإشارات مؤلَّفة بالموقع لا بالزوايا
اللغويون يصفون الإشارة بـ **موقعها** ("عند الذقن")، لا بزوايا مفاصلها. لذلك `kinematics.py` يحلّ IK تحليليًا: تكتب موقع الرسغ في الفضاء ويحسب هو زوايا الكتف والمرفق والرسغ (دقة 0.00 مم).

### 5. العلامات غير اليدوية نحوية
`browDown` لسؤال wh-، `browUp` لسؤال نعم/لا، هزّ الرأس للنفي. مُصرَّفة داخل نفس الـ clip كمسارات morph — لا كطبقة تجميلية.

### 6. التدهور اللطيف
انقطع الاتصال؟ الإضافة تهجّئ النص من قاموس محلي (42 مدخلًا) بلا أي طلب شبكة.

### 7. الإعداد عن بُعد
`GET /v1/config/{token}.json` — العميل يغيّر الألوان والميزات دون لمس كوده.

## الأمان — بصراحة

`X-Integrity` هو HMAC-SHA256 يُحسب في المتصفح من مفتاح **موجود في ملف JS**. أي شخص يستطيع استخراجه. هو **حاجز ضد إساءة الاستخدام العابرة، لا مصادقة**.

الحماية الفعلية في `checkOrigin()`: قائمة نطاقات مسموحة لكل token يُتحقق منها على السيرفر. هذا هو التصحيح الأهم على نموذج Hand Talk، الذي يُرسل `access-control-allow-origin: *`.

## الاختبارات

```
1. تكافؤ المُفكِّك    مُفكِّك JS مقابل مُصرِّف Python: 11,775 عيّنة عظام، أقصى فرق 3.2e-6
2. عقد الـ API        20 اختبارًا: الحالات، النحو، الأخطاء، تحديد المعدّل، HMAC، اجتياز المسار
3. الأصول             glTF صالح بلا أخطاء، ميزانيات الحجم، اكتمال القاموس
```

> **اختبار التكافؤ كشف خطأً حقيقيًا:** Python كان يُقحِم زوايا Euler خطيًا بينما three.js يُقحِم الكواتيرنيونات بـ slerp — منحنيان مختلفان بين المفاتيح. المُصرِّف كان يُنتج حركة مختلفة عمّا يراه المستخدم. أي نظام من هذا النوع يحتاج هذا الاختبار تحديدًا، لأن الخلل صامت تمامًا.

## واجهة التضمين

```html
<script defer src="/sla-plugin.js"></script>
<script>
  window.onload = () => {
    window.sla = new SignPlugin({
      token: 'demo_2f6a91c4e7b3',
      language: 'ase',
      avatar: 'NOOR',
    });
  };
</script>
```

**واجهة برمجية:**

| الدالة | الوصف |
|---|---|
| `sla.translate(text)` | ترجم نصًا وشغّله |
| `sla.open()` / `sla.close()` | فتح/إغلاق اللوحة |
| `sla.replay()` | إعادة آخر ترجمة |
| `sla.setSpeed(0.5–2)` | سرعة التشغيل |
| `sla.cycleAppearance()` | تدوير لون البشرة والملابس |
| `sla.destroy()` | إزالة كاملة (مستمعات + DOM + ذاكرة) |

**سمة مفيدة:** `data-sla-alt="نص بديل"` على أي عنصر يجعل الإضافة تترجم النص البديل بدل المحتوى المرئي.

## حدود هذا التنفيذ — بصراحة

هذا **نموذج هندسي كامل**، لا منتج جاهز للإنتاج:

- **الإشارات مُؤلَّفة برمجيًا، لا مُلتقطة من ممثل صمّ ولا مُراجَعة لغويًا.** الحركة معقولة تشريحيًا لكنها ليست ASL أصيلة. لا تنشرها لمستخدمين حقيقيين قبل مراجعة مترجمين صمّ.
- القاموس 22 gloss فقط — الباقي يُهجّأ.
- محرّك النحو يطبّق 4 قواعد ASL أساسية، لا التصريف المكاني ولا المُصنِّفات (classifiers).
- الأفاتار أسلوبي (مانيكان)، لا واقعي.

الطريق من هنا إلى الإنتاج موصوف في [`../docs/05-IMPLEMENTATION-ROADMAP.md`](../docs/05-IMPLEMENTATION-ROADMAP.md) و[`../docs/06-DATA-PIPELINE.md`](../docs/06-DATA-PIPELINE.md).
