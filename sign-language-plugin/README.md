# مشروع: إضافة ترجمة لغة الإشارة بأفاتار ثلاثي الأبعاد

> حزمة هندسية كاملة مبنية على **هندسة عكسية موثّقة** لإضافة Hand Talk (الإصدار `12.8.1` / core `2.4.0`)، مستخرجة من ثلاثة ملفات HAR التقطت دورة الحياة الكاملة: تحميل الصفحة → تفعيل الإضافة → تنفيذ الترجمة.

---

## ما هذا المستند؟

هذه ليست تخمينات معمارية. كل رقم وكل اسم حقل وكل نقطة نهاية (endpoint) في هذه الوثائق **مستخرج حرفيًا** من:

| الملف | المرحلة | عدد الطلبات |
|---|---|---|
| `Before starting-*.har` | تحميل الصفحة المضيفة قبل تفعيل الإضافة | 128 |
| `After starting-*.har` | لحظة الضغط على زر التفعيل | 20 |
| `When translating-*.har` | تحديد نص وطلب ترجمته | 10 |

بالإضافة إلى فكّ حزم JavaScript المحمّلة (`handtalk.min.js` 546 KB، `core.min.js` 809 KB) لاستخراج المنطق الفعلي.

## 🚀 التنفيذ العملي

المجلد [`impl/`](impl/README.md) يحوي **نظامًا يعمل فعليًا** بُني من الصفر على أساس هذا التحليل:
أفاتار مُهيكل أصلي (50 عظمة، 399 KB)، أبجدية ASL كاملة، محرّك ترجمة، خادم، وإضافة قابلة للتضمين بسطر واحد.

```bash
cd impl && npm install && npm run build && npm run dev
# → http://localhost:8787
```

## الخلاصة في 60 ثانية

Hand Talk **ليست** نموذج ذكاء اصطناعي يولّد الحركة في الزمن الحقيقي. هي:

1. **محرّك NLP على السيرفر** يحوّل الجملة إلى تسلسل *glosses* (وحدات إشارية).
2. **قاموس أنيميشن مسجّل يدويًا** (Motion Capture / Keyframe) لكل gloss.
3. **بروتوكول ضغط نصي مخصّص** (`HTA`) يرسل مسارات الدوران والتعابير كسلسلة نصية صغيرة (1 KB لجملة قصيرة) بدل ملفات BVH/glTF ثقيلة.
4. **مشغّل three.js** في المتصفح يفكّ الترميز إلى `AnimationClip` ويشغّله على هيكل عظمي من 119 عظمة و60 morph target.
5. **آلية احتياطية (fallback)**: أي كلمة غير موجودة في القاموس تُهجّأ حرفًا بحرف (fingerspelling) من قاموس محلي مضمّن في الـ bundle.

> النتيجة: تجربة "فورية" بتكلفة شبكة ~1 KB لكل جملة، دون أي GPU على السيرفر.

## نطاق هذا المشروع

- **لغة الإشارة المستهدفة:** ASL (American Sign Language) كنقطة انطلاق، مع طبقة تجريد تسمح بإضافة لغات أخرى.
- **المخرج:** إضافة JavaScript سطر واحد `<script>` قابلة للتضمين في أي موقع.
