01 — الفكرة الأساسية

ليست ذكاءً اصطناعيًا يولّد الحركة

الافتراض الشائع أن مثل هذه الأنظمة تُولّد حركة الأفاتار بنموذج عصبي في الزمن الحقيقي. هذا غير صحيح. Hand Talk تعمل بمبدأ الاسترجاع من قاموس (retrieval) لا التوليد (generation): محرّك لغوي على السيرفر يحوّل الجملة إلى تسلسل من الوحدات الإشارية، ولكل وحدة أنيميشن مسجّل مسبقًا بيد فنانين ومترجمين صمّ.

03 — الابتكار الحقيقي

بروتوكول HTA: حركة كاملة في كيلوبايت واحد

هذا هو الجزء الذي يميّز النظام تقنيًا. بدل إرسال ملفات glTF أو BVH ثقيلة، ابتكروا صيغة نصية مضغوطة تنقل مسارات الدوران وتعابير الوجه في مساحة ضئيلة.

تشريح مسار واحد

BT*11#16#21*-194#-194#-194*63#63#63*200#201#200
BT — كود العظمة، يقابل ORG-handL (اليد اليسرى)
أرقام الإطارات المفتاحية عند 24 إطارًا/ثانية
الدوران حول المحور X (درجات ÷ 2.7، عدد صحيح)
الدوران حول المحور Y
الدوران حول المحور Z

مثال ثانٍ: رمشة عين في 16 بايت

UM*7#11#16*#100#
UM — يبدأ بحرف من U..Z ⇒ هدف تعبير وجهي (OLHO.PISCA.R)
الإطارات 7 و11 و16
القيم 0, 100, 0 ← الفراغ يعني صفرًا · ÷100 ⇒ التأثير 0.0 → 1.0 → 0.0

الفاصل ?

يفصل بين المسارات — كل مسار عظمة واحدة أو هدف وجهي واحد.

الفاصل *

يفصل حقول المسار: الكود، الإطارات، ثم القنوات X و Y و Z.

الفاصل #

يفصل القيم داخل الحقل. القيمة الفارغة تعني صفرًا.

مصادر الكفاءة الخمسة

  • مفاتيح فقط، لا إطارات مُستوفاة — ثلاثة أرقام تصف مسارًا كاملًا.
  • حذف المسارات الساكنة — العظمة التي لا تتحرك لا تُرسل؛ المُفكِّك يعيدها لوضع الراحة.
  • الفراغ يساوي صفرًا — BQ*11*215** يعني X=215، Y=0، Z=0.
  • أعداد صحيحة مضغوطة — الزوايا مقسومة على 2.7 ومحفوظة كأعداد صحيحة.
  • رموز من حرفين — BT بدلًا من "ORG-handL".

خوارزمية فكّ الترميز

const FPS = 24, ANGLE_DIVISOR = 2.7;

const decodeTrack = (raw, boneMap, morphMap, meshName, offset) => {
  const [code, frames, chX, chY, chZ] = raw.split('*');
  const longName = CODE_TABLE[code];
  const isMorph  = 'UVWXYZ'.includes(code[0]);   // ← قاعدة التمييز
  const times    = frames.split('#')
                        .map(v => (parseInt(v || '0') / FPS) + offset);

  return isMorph
    ? { name: `${meshName}.morphTargetInfluences[${morphMap[longName]}]`,
        times, type: 'number', values: parseMorph(chX, times.length) }
    : { name: `${boneMap[longName]}.quaternion`,
        times, type: 'quaternion',
        values: buildQuats(chX, chY, chZ, times.length) };
};
خطوة حاسمة لا تُهملها: بعد فكّ كل المسارات الموجودة، يجب إضافة مسار هوية ([0,0,0,1]) لكل عظمة لم تُذكر في السلسلة. بدون ذلك تتراكم أوضاع الإشارات السابقة وينهار الأفاتار بصريًا بعد بضع إشارات.

الهيكل العظمي: 119 عظمة + 60 تعبيرًا

توزيع العظام

اليدان والأصابع 74 · الساقان 20 · الكتف والذراع 16 · الجذع والرأس 9.

62% من الميزانية العظمية في اليدين — لأن شكل اليد (handshape) أحد المعاملات الخمسة الأساسية لأي إشارة. rig مبسّط لليد = نظام غير قابل للاستخدام.

تعابير الوجه — ليست زينة

رفع الحاجبين = سؤال نعم/لا · خفضهما = سؤال wh- · هزّ الرأس = نفي. هذه علامات نحوية. جملة بدون رفع الحاجبين ليست سؤالًا، بل جملة خبرية.

أسماء الأهداف بالبرتغالية (SOBRANCELHA.DENTRO.SOBE.R) — دليل على أن النظام بُني أولًا للغة الإشارة البرازيلية.

بصمة تكشف أداة الإنتاج: أسماء العظام تتبع نمط DEF- و ORG- — وهو اصطلاح Rigify في Blender. الأفاتار مُهيّأ في Blender، والحركة تُصدَّر بسكربت Python مخصّص.
04 — تجربة المستخدم

كيف يُلتقط النص من الصفحة؟

هذا الجزء يحدّد ما إذا كانت الإضافة ستكسر الموقع المضيف أم لا — وهو أكثر ما يُخطئ فيه المهندسون عند بناء إضافات طرفية.

الوضع الافتراضي: النقر

نقرة على أي عنصر يحوي نصًا تُشغّل الترجمة فورًا. الأسرع للاستخدام اليومي.

الوضع البديل: التحديد

تحديد نص بالماوس أو اللمس. مناسب لفقرات محدّدة داخل نص طويل.

const listeners = [
  ['mouseup',         e => schedule(e)],
  ['touchend',        e => schedule(e)],
  ['keyup',           e => { if (e.shiftKey || e.ctrlKey ||
                            e.metaKey || e.key === 'Escape') schedule(); }],
  ['selectionchange', () => hasSelection() ? schedule() : clear()],
];
// debounce بمقدار 10ms قبل قراءة التحديد

استخراج النص — مع احتياطي ARIA

switch (el.tagName.toLowerCase()) {
  case 'select': text = el.options?.[el.selectedIndex]?.innerText; break;
  case 'img':    text = el.getAttribute('data-ht-alt') || el.alt;    break;
  case 'button': text = el.innerText || el.textContent || el.value;
  default:      text = el.innerText || el.textContent;
}
// احتياطي: سمات ARIA
if (!text) text = firstAttr(el, ['aria-label', 'aria-describedby',
                                 'aria-description']);

السمة data-ht-alt

تسمح لمالك الموقع بكتابة وصف بديل مُحسَّن للإشارة، مختلف عن alt العادي. تفصيلة صغيرة وذكية جدًا.

احترام الروابط والأزرار

العناصر ضمن clickables لا تُعترض — يظهر بدلًا من ذلك سؤال للمستخدم. الموقع يبقى قابلًا للاستخدام.

عزل الأنماط

كل CSS الإضافة مُنطّق داخل الصنف .ht-skip. لا تسريب أنماط للموقع المضيف.

attachIntegrityHeaders = async (payload) => {
