## 2. المتطلبات غير الوظيفية

### NFR-1 — الأداء

| # | المتطلب | الهدف | مرجع Hand Talk |
|---|---|---|---|
| NFR-1.1 | حجم الحزمة الأساسية (gzip) | **< 150 KB** | 546 KB خام |
| NFR-1.2 | حجم محرك 3D (gzip، عند الطلب) | **< 250 KB** | 809 KB خام |
| NFR-1.3 | حجم موديل الأفاتار | **< 2 MB** | **3.57 MB** ← نتفوّق بـ Draco/KTX2 |
| NFR-1.4 | زمن الترجمة (p95، جملة قصيرة) | **< 400 ms** | 418 ms |
| NFR-1.5 | معدل الإطارات على جهاز متوسط | **≥ 30 fps** | — |
| NFR-1.6 | تأثير صفري على LCP للموقع المضيف | 0 ms | ✅ (`defer`) |
| NFR-1.7 | زمن التفعيل الكامل (شبكة سريعة) | **< 3 s** | ~4.5 s |

> **NFR-1.3 هو أكبر فرصة تفوّق.** Hand Talk تُقدّم `.gltf` نصيًا غير مضغوط بحجم 3.57 MB. باستخدام `.glb` + ضغط Draco للهندسة + KTX2/Basis للنسيج، يمكن الوصول إلى 800 KB – 1.5 MB مع جودة مماثلة.

| NFR-2.4 | عدم التعارض مع jQuery / GTM / أي مكتبة على الصفحة |

### NFR-3 — الأمان

| # | المتطلب |
|---|---|
| NFR-3.1 | HTTPS إلزامي |
| NFR-3.2 | توقيع HMAC-SHA256 على كل طلب |
| NFR-3.3 | **قائمة نطاقات مسموحة لكل token — يُتحقق منها على السيرفر** |
| NFR-3.4 | تحديد معدّل لكل token + IP |
| NFR-3.5 | جلسات منتهية الصلاحية (~15 دقيقة) |
| NFR-3.6 | تنقية كل نص مُلتقط بـ DOMPurify قبل العرض |
| NFR-3.7 | عدم تسريب مفاتيح فعلية إلى الواجهة |
| NFR-3.8 | احترام `doNotTrack` من المتصفح |

> **NFR-3.3 هي التصحيح الأهم على نموذج Hand Talk.** مفتاح HMAC لديهم مكشوف في الـ JS. الحماية الحقيقية = ربط الـ token بنطاقات محددة والتحقق من `Origin` على السيرفر.

## 3. مصفوفة التقنيات

### الواجهة الأمامية — القشرة

| المكوّن | الاختيار | البديل | السبب |
|---|---|---|---|
| مكتبة الواجهة | **Preact 10** | React, Svelte | 4 KB مقابل 45 KB — حرج للسكربتات الطرفية |
| إدارة الحالة | **zustand** | Redux, nanostores | ~1 KB، API بسيط |
| أداة البناء | **Vite + Rollup** | Parcel, esbuild | تقسيم كود ممتاز + tree-shaking |
| اللغة | **TypeScript 5** | JS | إلزامي لبروتوكول معقد |
| التنقية | **DOMPurify** | — | معيار الصناعة |
| الأنماط | **CSS-in-JS منطّق** | Shadow DOM | Shadow DOM أنظف لكنه يُعقّد التقاط النص |

### الواجهة الأمامية — محرك 3D

| المكوّن | الاختيار | البديل | السبب |
|---|---|---|---|
| محرك | **three.js (أحدث LTS)** | Babylon.js | نظام بيئي أكبر، حجم أصغر |
| تحميل الموديل | **GLTFLoader + DRACOLoader** | — | ضغط الهندسة |
| النسيج | **KTX2Loader + Basis** | PNG/JPG | ضغط GPU الأصلي |
| الأنيميشن | **AnimationMixer + QuaternionKeyframeTrack** | — | مدمج |
| بناء الحزمة | استيراد انتقائي من three | الحزمة كاملة | ~40% توفير |

> **⚠️ ملاحظة:** Hand Talk تستخدم three.js **r117** (2020). لا تنسخ هذا القرار — استخدم إصدارًا حديثًا للحصول على تحسينات الأداء وWebGPU مستقبلًا.

## 4. مخاطر المشروع

| المخاطرة | الأثر | الاحتمال | التخفيف |
|---|---|---|---|
