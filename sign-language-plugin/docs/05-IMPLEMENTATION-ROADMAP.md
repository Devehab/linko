# 05 — خارطة التنفيذ

ستة مراحل، كل واحدة لها مخرج قابل للعرض ومعايير قبول صريحة.

> **التقديرات بوحدة "أسبوع-مهندس"** وتفترض فريقًا من: مهندس واجهات، مهندس 3D/رسوميات، مهندس خلفية، لغوي إشاري (بدوام جزئي).

---

## المرحلة 0 — إثبات المفهوم التقني (2–3 أسابيع)

**الهدف:** إثبات أن السلسلة كاملة تعمل، بإشارة واحدة فقط.

### المهام

1. تجهيز أفاتار بسيط في Blender بـ Rigify (~119 عظمة، 20 morph target للبداية).
2. تسجيل أو تحريك يدوي لإشارة واحدة (`HELLO`).
3. كتابة سكربت Python داخل Blender: `glTF/Action` → `HTA`.
4. كتابة مُفكِّك HTA في TypeScript → `THREE.AnimationClip`.
5. صفحة HTML بسيطة تُشغّل الإشارة.

### مواصفة صيغة HTA (نسختك)

```
HTA        := Track ( "?" Track )*
Track      := Code "*" Frames "*" ChanX [ "*" ChanY "*" ChanZ ]
Code       := [A-Z]{2}                 ; B–F = عظام، U–Z = morph targets
Frames     := Int ( "#" Int )*         ; أرقام إطارات عند 24 fps
Value      := Int | ""                 ; "" = 0
```

**العظام:** الزوايا بالدرجات مقسومة على `2.7`، مخزّنة كأعداد صحيحة.
**Morph targets:** التأثير × 100، عدد صحيح 0–100.

### كود المُفكِّك (نقطة انطلاق جاهزة)

```ts
const FPS = 24;
const ANGLE_DIVISOR = 2.7;

interface DecodedTrack {
  name: string;
  times: Float32Array;
  values: Float32Array;
  type: 'quaternion' | 'number';
}

function decodeHTA(
  hta: string,
  boneMap: Record<string, string>,     // longName → boneNodeName
  morphMap: Record<string, number>,    // longName → morphIndex
  meshName: string,
  offset = 0.2
): DecodedTrack[] {
  const tracks: DecodedTrack[] = [];
  const seen = new Set<string>();

  for (const raw of hta.split('?')) {
    if (!raw) continue;
    const [code, framesStr, cx, cy, cz] = raw.split('*');
    const longName = CODE_TABLE[code];
    if (!longName) throw new Error(`كود غير معروف: ${code}`);

    const times = new Float32Array(
      framesStr.split('#').map(v => (parseInt(v || '0', 10) / FPS) + offset)
    );

    if ('UVWXYZ'.includes(code[0])) {
      const name = `${meshName}.morphTargetInfluences[${morphMap[longName]}]`;
      tracks.push({ name, times, values: parseMorph(cx, times.length), type: 'number' });
      seen.add(name);
    } else {
      const name = `${boneMap[longName]}.quaternion`;
      tracks.push({ name, times, values: buildQuats(cx, cy, cz, times.length), type: 'quaternion' });
      seen.add(name);
    }
  }

  // إعادة كل ما لم يُذكر إلى وضع الراحة — خطوة إلزامية
  for (const b of Object.keys(boneMap)) {
    const name = `${boneMap[b]}.quaternion`;
    if (!seen.has(name))
      tracks.push({ name, times: new Float32Array([0]),
                    values: new Float32Array([0,0,0,1]), type: 'quaternion' });
  }
  for (const m of Object.keys(morphMap)) {
    const name = `${meshName}.morphTargetInfluences[${morphMap[m]}]`;
    if (!seen.has(name))
      tracks.push({ name, times: new Float32Array([0]),
                    values: new Float32Array([0]), type: 'number' });
  }
  return tracks;
}

function toClip(name: string, tracks: DecodedTrack[]): THREE.AnimationClip {
  return new THREE.AnimationClip(name, -1, tracks.map(t =>
    t.type === 'quaternion'
      ? new THREE.QuaternionKeyframeTrack(t.name, t.times, t.values)
      : new THREE.NumberKeyframeTrack(t.name, t.times, t.values)
  ));
}
```

### معايير القبول

- [ ] إشارة واحدة تُعرض بشكل صحيح في المتصفح
- [ ] حجم HTA للإشارة **< 3 KB**
- [ ] ≥ 30 fps على MacBook متوسط
- [ ] رحلة ذهاب وإياب: Blender → HTA → متصفح تعمل آليًا

## المرحلة 1 — الأساس ثلاثي الأبعاد (4–6 أسابيع)

**الهدف:** مشغّل أفاتار كامل الميزات.

### المهام

1. إنتاج أفاتار نهائي: تهيئة كاملة + 60 morph target + تحسين للويب.
2. خط أنابيب الأصول: `.blend` → `.glb` + Draco + KTX2.
3. مشغّل الأنيميشن: طابور، crossfade 0.2s، تحكم بالسرعة، إيقاف/استئناف.
4. طبقة العرض: renderer شفاف، إعداد إضاءة، تعامل مع تغيير الحجم مع debounce.
5. تحسين الأداء: LOD، تقييد DPR بين 1 و1.75، `fpsLimit`.

### معايير القبول

- [ ] حجم الأفاتار **< 2 MB** بعد الضغط
- [ ] 20 إشارة متتالية تعمل دون انحراف بصري (drift)
- [ ] ≥ 30 fps على iPhone 12 و Android متوسط
- [ ] الخلفية شفافة تمامًا
- [ ] لا تسرّب ذاكرة بعد 100 تشغيل (تحقق من `destroy()`)

## المرحلة 2 — بناء القاموس (8–16 أسبوعًا — يتوازى مع كل شيء)

> **هذه المرحلة هي المسار الحرج للمشروع كله.** ابدأها في اليوم الأول.

### المهام

1. **تحليل تكرار المفردات:** استخرج أكثر 1000 كلمة شيوعًا من مواقع مستهدفة.
2. **تجنيد فريق لغوي:** مترجمان معتمدان + ممثل صمّ للأداء.
3. **إعداد استوديو الالتقاط:** بدلة Rokoko + قفازات Manus + iPhone لـ ARKit.
4. **دورة الإنتاج:** التقاط → تنظيف في Blender → تصدير HTA → مراجعة → نشر.
5. **أداة المراجعة:** واجهة ويب تعرض الإشارة وتسمح بالموافقة/الرفض/التعليق.

### أهداف الإنتاج

| الفترة | عدد الإشارات | التغطية التقريبية |
|---|---|---|
| الشهر 1 | 200 | الحروف + الأرقام + 150 كلمة أساسية |
| الشهر 3 | 800 | ~60% من النص الشائع |
| الشهر 6 | 2000 | ~80% |
| السنة 1 | 5000 | ~92% |

> الباقي يُغطّى بالتهجئة الإصبعية — وهو سلوك طبيعي ومقبول لغويًا.

### معايير القبول

- [ ] 200 إشارة مراجَعة ومنشورة
- [ ] كل إشارة تحمل `reviewed_by` و `reviewed_at`
- [ ] زمن الدورة لكل إشارة **< 45 دقيقة**
- [ ] معدل الموافقة في المراجعة **> 85%**

## المرحلة 3 — محرك الترجمة (6–8 أسابيع)

**الهدف:** نص → تسلسل glosses.

### خط الأنابيب

```
النص الخام
  │
  ├─ 1. التطبيع        حذف &nbsp;، توحيد المسافات، إزالة الأسطر الزائدة
  ├─ 2. تقسيم الجُمل    مع التعامل مع الاختصارات (Dr., U.S.)
  ├─ 3. الترميز         Tokenization + POS tagging (spaCy)
  ├─ 4. التصريف الأساسي  running → run
  ├─ 5. حذف الوظيفية    is, the, of, a, an, by  ⇒  []
  ├─ 6. إعادة الترتيب    حسب نحو لغة الإشارة (Topic-Comment في ASL)
  ├─ 7. بحث القاموس     lemma → gloss_id
  └─ 8. احتياطي         غير موجود ⇒ تهجئة إصبعية
```

### قواعد النحو الأساسية لـ ASL (المرحلة الأولى)

| القاعدة | مثال |
|---|---|
| ترتيب Topic-Comment | "I like pizza" → `PIZZA I LIKE` |
| ظروف الزمن أولًا | "I went yesterday" → `YESTERDAY I GO` |
| حذف أفعال الكينونة | "She is a doctor" → `SHE DOCTOR` |
| حذف أدوات التعريف | "the house" → `HOUSE` |
| السؤال في النهاية + رفع حاجب | "Where is it?" → `IT WHERE` + morph |
| النفي بعد الفعل | "I don't know" → `I KNOW NOT` |

> **كن متواضعًا:** ابدأ بمحرك قواعد (rule-based). النماذج العصبية لترجمة الإشارة لا تزال بحثية وغير موثوقة إنتاجيًا.

### معايير القبول

- [ ] `/translate` p95 **< 300 ms**
- [ ] مجموعة اختبارات من 200 جملة مع مخرجات متوقعة يراجعها اللغوي
- [ ] معدل إصابة الذاكرة المؤقتة **> 60%** بعد يوم من التشغيل
- [ ] معالجة صحيحة لـ `[]` (الحذف النحوي)

## المرحلة 4 — قشرة الإضافة (5–7 أسابيع)

**الهدف:** الإضافة الجاهزة للتضمين.

### المهام

1. **حاقن السكربت:** `new SignPlugin({})`، حارس تعدد النسخ، تحميل كسول لمحرك 3D.
2. **ملتقط النص:** وضعا النقر والتحديد، الاستثناءات، مؤشرات مخصصة، حد 800 حرف.
3. **الواجهة (Preact):** زر عائم، لوحة الأفاتار، شريط التحكم، الترجمة النصية، القوائم.
4. **عميل الترجمة:** توقيع HMAC، إدارة الجلسة، إعادة المحاولة مع تراجع أسّي.
5. **الإعداد عن بُعد:** جلب + دمج بالأولوية الصحيحة.
6. **العزل:** كل CSS داخل `.sp-skip`، لا تلوّث عالمي عدا `window.SignPlugin`.
7. **التحليلات المعزولة:** iframe + `postMessage`.

### معايير القبول

- [ ] الحزمة الأساسية **< 150 KB** gzip
- [ ] تعمل على 20 موقعًا شائعًا دون كسر أي شيء
- [ ] `destroy()` تنظّف كل شيء (مستمعات، DOM، ذاكرة)
- [ ] لوحة الإضافة نفسها تجتاز WCAG 2.1 AA
- [ ] الرحلة الكاملة تعمل بدون إنترنت (تهجئة)

## المرحلة 5 — الإنتاج والتوسّع (4–6 أسابيع)

### المهام

1. **البنية التحتية:** CDN، حاويات، تلقائية التوسّع، فحوص صحة.
2. **المراقبة:** OpenTelemetry، لوحات زمن الاستجابة/الأخطاء/معدل الذاكرة المؤقتة.
3. **لوحة تحكم العملاء:** إدارة الـ token، النطاقات المسموحة، محرر الإعداد، الإحصائيات.
4. **التوثيق:** دليل التضمين، مرجع API، أمثلة على أطر العمل الشائعة.
5. **الفوترة:** حدود المستويات، فرض تحديد المعدل.

### معايير القبول

- [ ] توفّر **99.9%**
- [ ] `/translate` p95 **< 400 ms** تحت 100 طلب/ثانية
- [ ] تنبيهات مضبوطة (لا ضجيج)
- [ ] عميل تجريبي حقيقي يستخدم النظام في الإنتاج

## 8. أخطاء يجب تجنّبها

| الخطأ | لماذا هو قاتل |
|---|---|
| بناء المحرك التقني أولًا وترك القاموس للنهاية | القاموس هو المسار الحرج — سيؤخّرك 6 أشهر |
| إهمال تعابير الوجه | الترجمة ستكون غير مفهومة، لا "ناقصة" |
| ترجمة كلمة بكلمة | لغة الإشارة لغة مستقلة، لا شفرة للإنجليزية |
| بناء المنتج دون مشاركة صمّ | سيُرفض بغض النظر عن جودته التقنية |
| نسخ three.js r117 | إصدار من 2020؛ استخدم الحديث |
| تقديم `.gltf` غير مضغوط | 3.5 MB مقابل 1 MB ممكنة |
| الاعتماد على HMAC في الواجهة كأمان | المفتاح مكشوف؛ استخدم قائمة نطاقات على السيرفر |
| الوعد بترجمة مثالية | كن صريحًا مع المستخدمين حول الحدود |
